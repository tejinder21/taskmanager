# Task Manager

Task Manager on Spring Bootilla toteutettu full stack -tehtävienhallintasovellus, joka mahdollistaa tehtävien luomisen, muokkaamisen, poistamisen ja tilan seuraamisen.

## Features
- Tehtävien luonti, haku, päivitys ja poisto (CRUD)
- Prioriteetin hallinta (1–3)
- Tilan seuranta (Not Started, In Progress, Completed)
- Kategoriatuki
- REST API -rajapinta
- Frontend yhdistetty backend-palveluun

## Technologies
- Java
- Spring Boot
- REST API
- Maven

## Running the project
```bash
./mvnw spring-boot:run
